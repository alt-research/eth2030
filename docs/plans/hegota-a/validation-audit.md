# Current validation, stub and experimental-path audit

HGT-008. Baseline: integrated master `89b3b1f2`, plus the bounded A follow-up. The [criterion matrix](../../../specs/hegota/acceptance.json) names actual executed tests. This audit covers the named EL acceptance boundaries; it is not a security certification of every algorithm or helper in the repository. The [pre-merge caller inventory](https://github.com/alt-research/eth2030/blob/6a17479/docs/plans/hegota-a/validation-audit.md) remains historical.

| Current caller / boundary | Behavior and negative evidence | Remaining responsibility |
| --- | --- | --- |
| `epbs.ValidateBuilderBid` -> legacy auction/bid validator | Nil, zero key/signature and nonzero self-supplied authentication inputs fail closed. Structural validation is not trusted CL authentication. `TestBuilderBidNeverAcceptsUnauthenticatedInput` checks all four. | Canonical SSZ/domain/registry verification belongs to the admitted CL/ePBS composition. |
| Native Bogota backend | `node/backend/engine_bogota.go` processes deferred payload/list views and FCU. It is not the retired local builder-authority API. Wire/restart and malformed-version controls exercise the native backend. | Independent CL/network agreement remains explicit. |
| Retired local builder methods | `builder_api.go` and authority submission methods were removed upstream; do not revive or advertise them to satisfy an obsolete audit table. | Keep capability negotiation consistent with actual methods. |
| BLS interfaces -> consensus backend | Reuse shared canonical gnark decoding/hash-to-curve/pairing. Independent fixed blst vector plus altered/zero/infinity/truncated inputs and backend-selection failures are tested. No secret-registry or re-sign fallback. | Explicit uncompiled blst selection fails, rather than silently claiming that backend. |
| PQ metadata registry | `VerifyRegistration` rejects the publicly computable historical digest. `RegisterKey` stores metadata and does not authenticate an owner. `TestVerifyRegistration` is a negative authentication control. | Selected 8483/8504 request/ownership/PoP composition remains conditional. |
| FOCIL helper / helper Engine | Missing post-state, unrecoverable sender or missing Frame prefix verifier yields unavailable, not a fabricated satisfied/unsatisfied verdict. Tests cover each. | Native Bogota is separately implemented; helper results cannot qualify its CL contract. |
| Blob bundle helper | Missing KZG verifier returns `ErrVerifierUnavailable` without retaining the blob; invalid commitment/proof rejects. `TestBlobsBundleMissingVerifierFailsClosed`. | Model-verifier helper tests are not native cryptographic verification evidence. |
| Native node KZG initialization | `bls.NewGoEthKZGBackend` failure returns a node-construction error. No zero-proof fallback or partially verified runnable node is constructed. | Production backend/setup remains mandatory. |
| Real snap/state persistence | Native snapshot/sync backends from master remain wired. Unknown state roots fail iteration, proof and trie-node queries in `TestNativeSnapRejectsUnknownStateRoots`. Deleted stub writers are not restored. | Full sync/recovery/interoperability qualification stays in HGT-087. |
| Canonical versus frozen legacy Frames | Current canonical codec/executor/pool are reused; the legacy format requires explicit opt-in and block/time prerequisites. Reorg/VM isolation tests apply. | No permissive shared decoder or default legacy activation. |
| AA / LocalTx / STARK | AA and LocalTx defaults reject those models. Enabling unsupported STARK validation fails node creation with `ErrFrameProofUnavailable`. | Supplying an experimental flag does not turn a model into protocol conformance. |
| Unwired beam/custody and structural-only signature helpers | Missing real sources return unavailable/error; structural checks are not authentication. These are not substituted for native snap or trusted CL paths. | Real networking and selected-profile validation remain later tasks. |

The acceptance gate requires current artifact hashes and actual passing test events for bid authentication, BLS, PQ, KZG, native backend, unavailable IL evidence and experimental gates. A test environment must not bypass those production decisions. The current runtime/head tests also verify the real dispatcher and canonical selection, not a hand-wired replacement backend.
