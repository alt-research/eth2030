# Pre-merge audit

- [ ] Refresh every open project PR, exact head/base, CI/check status and review blockers; include sibling runtime prerequisites.
- [ ] Re-run individual, pairwise and cumulative merge compatibility against current targets.
- [ ] Review every pending functional diff, production consumers, failure/recovery and test-only boundaries.
- [ ] Run qualified composition regressions/build and meaningful additional checks for any findings.
- [ ] Separate verified changes, bounded qualification, known blockers and unconfirmed original-fault questions.
- [ ] Publish a concrete merge order/checklist and exact-head handoff, then stop without merging.
