# Pre-merge audit

- [x] Refresh every open project PR, exact head/base, CI/check status and review blockers; include sibling runtime prerequisites.
- [x] Re-run individual, pairwise and cumulative merge compatibility against current targets.
- [x] Review every pending functional diff, production consumers, failure/recovery and test-only boundaries.
- [x] Run qualified composition regressions/build and meaningful additional checks for any findings.
- [x] Separate verified changes, bounded qualification, known blockers and unconfirmed original-fault questions.
- [x] Publish a concrete merge order/checklist and exact-head handoff, then stop without merging.
