# Historical receipt and transaction metadata recovery

The real rolling application campaign exposed a retained deployment receipt reporting effectiveGasPrice 0, no creation address and an empty sender after restart, despite matching consensus receipt gas/logs. The persistent reader now restores transaction sender caches from the stored envelopes and reconstructs derived fees, blob/calldata fee fields and creation addresses against the exact authenticated historical header. Private frame decoding and PQ/embedded-sender handling remain explicit. Historical high-S signatures are read using their original recovery semantics. These are readback caches, not a new transaction-admission authority.

A further actual HTTP regression found failed contract creation reported no attempted CREATE address even in the hot path. The ordinary processor now reports the same nonce-derived attempted address as unchanged Geth, for both success and failure, without changing consensus receipt bytes or EVM state transitions.

Eight closed/reopened FileDB cases compare standard envelope metadata, pre-Homestead high-S/post-state receipts, nonce-128 creation, fee-capped and zero-base-fee transactions, and nontrivial blob pricing against unchanged Geth receipt derivation. The actual two-fork Node HTTP/Engine regression admits all five real signed standard envelopes, including a real version-1 blob sidecar with 128 KZG proofs. It compares complete receipts and signed-transaction senders while hot, after forced block/receipt-cache eviction, and after actual Node database restart. Complete headers and receipt tries are independently reconstructed and canonical commitments remain unchanged.

Affected chain/execution/rpc tests and the actual Node regression pass. Four restored behavior mutations (omitted persistent metadata, omitted sender restoration, omitted blob price, old failed-CREATE address) fail at their intended independent or real-HTTP assertions. At clean source ec9be275, all 214 full-package Go tests, affected chain/execution/node/rpc race tests, core/p2p integration, full go vet and the actual cmd/eth2030 build pass after restoring every mutation. Actual runtime continuation remains in progress.
