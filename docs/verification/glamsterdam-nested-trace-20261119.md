## Versioned behavior

Development schema inputs are [execution-apis 855](https://github.com/ethereum/execution-apis/pull/855), call-frame schema `d8409a1d`, [852](https://github.com/ethereum/execution-apis/pull/852), dimensional schema `cc1852a7`, and merged Geth [35970](https://github.com/ethereum/go-ethereum/pull/35970), merge `bf8ae65c`. The current LIFO execution target remains EIPs `3db38a3`, explicitly selected by the user with final design review retained. Proposals 855/852 and settlement 35954 remain open. Issue 976's alternative nested state usage is not mixed into the root-only policy. This is a concrete development target, not final API adoption.

Actual HTTP originally returned no call tree for named traceCall and omitted the dimensional fields. Frame enter/exit and transaction settlement now supply real CALL/CALLCODE/DELEGATECALL/STATICCALL/CREATE/CREATE2/SELFDESTRUCT trees. Empty values and reservoirs retain their required presence; failed creates omit their address; static frames omit value. Root gas is the full transaction limit and root gasUsed is paid receipt gas. Nested gasUsed is actual execution-budget consumption, including state spill when the reservoir cannot pay it. The caller's full reservoir enters children independently of the 63/64 execution-gas rule.

Root regular/state/refund fields appear only after Amsterdam and only on root frames. Opcode gasCost excludes state creation even when that state cost is drawn from gas_left. Signed stateGasCost and pre-step reservoirs appear only when nonzero. Storage snapshots use actual post-execution storage; stack, memory, return-data and step-limit options retain their omission semantics. Failed pre-meter steps are recorded with zero cost. OnlyTopCall/withLog use real frame/log events, preserve block-global receipt indices and clear reverted descendants' logs. SELFDESTRUCT's implicit protocol log belongs to the executing frame before its synthetic zero-gas child, matching the independent SDK.

Single transaction replay retains the actual prefix and its log offset; block traces replay once. Trace calls inherit the given block and apply state/context overrides without simulated-block increments. Validation errors, unsupported tracers, unavailable state, execution timeout and capture-capacity failures return an RPC error rather than fabricated or partial results. Capture retention is limited to twice the existing VM memory bound (64 MiB); the standard explicit step limit stops capture while execution continues.

## Actual consumers and independent checks

Nine classic call trees match unmodified Geth v1.17.10 across state spill, successful/reverted logs, onlyTopCall, delegated/callcode contexts, static failure, CREATE2 memory padding and SELFDESTRUCT. The comparison excludes exactly four dimensional fields unavailable in that SDK, and normalizes only permitted non-REVERT failure text by class. REVERT text and the rest of the tree remain exact. Dimensional fields are checked separately against exact charges and actual receipt/block consumers, not declared independently verified by an SDK that does not emit them.

Two real signed funded transactions enter the native pool, build/import/select through HTTP Engine APIs and produce receipts. Their root regular/state counters reconcile with paid gas and the bottleneck header total. A child allocation consumes 12106 execution plus its LOG cost from gas_left while its 97920 state gas comes from the reservoir; the unfunded child consumes the additional spill. The second transaction's log index remains 3 under individual prefix replay and onlyTopCall. Fork tests omit proposed fields before Amsterdam and verify a calldata-floor case where regular plus state gas is deliberately greater than paid gas plus refund.

The work independently reproduced and repaired two execution-boundary defects. [EIP-211](https://eips.ethereum.org/EIPS/eip-211) requires an empty return buffer on each new call frame; the second child previously inherited 32 bytes. Resetting at call/create boundaries fixes actual eth_call while preserving raw EOF interpreter tests unchanged. [EIP-214](https://eips.ethereum.org/EIPS/eip-214) forbids state writes before charging the rejected opcode; the old static SSTORE trace charged 12100 before the write-protection exception. The precheck now occurs before metering and respects CALLCODE's value exception.

All 212 Go packages, 27 tagged Core/EIP packages and 48 affected race packages pass, with affected vet and local build. Seventeen compiling mutations detect frame presence, spill gas, failed-create address omission, zero/old-fork/root-only field presence, reverted logs, prefix indices, reservoir forwarding, state/regular opcode cost, storage timing, step limits, read-only timing, new-frame buffers and capture capacity. Sources are restored before final checks. The later simulator documentation-only composition is rechecked separately.

Durable logs use `/projects/eth2030/glamsterdam-nested-trace-*`, including original red cases, nine SDK comparisons, actual signed/block consumers, capacity/timeout controls, mutation failures and final full/tagged/race runs. Canonical head/root/balances/nonces remain unchanged by tracing; rejected creation and storage operations do not leak adopted state.
