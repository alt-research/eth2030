## Selected inputs and delivered behavior

The complete selected [method schema](https://github.com/ethereum/execution-apis/blob/68d76a5b1c09dff023782d97eec6ce87a6f6505e/src/eth/execute.yaml), [simulation and override schema](https://github.com/ethereum/execution-apis/blob/68d76a5b1c09dff023782d97eec6ce87a6f6505e/src/schemas/execute.yaml) and [simulation notes](https://github.com/ethereum/execution-apis/blob/68d76a5b1c09dff023782d97eec6ce87a6f6505e/docs-api/docs/ethsimulatev1-notes.mdx) were read alongside the full unmodified Geth v1.17.10 simulator. Execution uses the explicitly selected merged LIFO model at EIPs `3db38a3`; pending gas alternatives are excluded.

Actual Node HTTP initially returned method-not-found. The new method executes sequential calls and blocks on isolated state, including pre-execution systems, withdrawals, execution requests and correctly indexed BAL. State overrides precede system operations and do not appear as BAL changes. The response contains complete calculated block commitments, unsigned transaction hashes or full objects, actual call status/output/logs and paid/peak gas. It never submits transactions, changes forkchoice or writes simulated blocks/state to canonical storage.

Validation-enabled simulation keeps nonce/fee checks and the capped execution/overflow reservoir policy while permitting contract senders. Disabled validation uses uncapped call execution with zero initial reservoir; both reserve the actual available execution/state dimensions. Default consecutive calls use the correct remaining budget. The 50M request gas budget is consumed across blocks; limits are 256 blocks including gaps, 5000 calls per block, 10000 calls total and a five-second execution deadline. VM cancellation also bounds overridden system-code loops.

Block overrides, complete/differential state overrides, precompile code replacement and relocation are applied to request-owned context. Original fork precompile addresses remain the warm set; moving a precompile does not warm its destination or mutate global maps. Unsupported override keys and conflicting aliases fail explicitly. Increasing block numbers may introduce real empty simulated blocks; time/number errors have their specified codes. Hash-selected bases follow that branch's ancestry, rather than the current canonical chain. Unknown parent slots remain omitted.

Before Amsterdam, requested virtual ETH transfer logs are ordered and rolled back with execution, but excluded from receipts/bloom/hash. After Amsterdam the normal EIP-7708 logs are returned once and are part of receipt commitments. Failed frames leave no transfer logs. Balances near uint256's boundary reproduce the SDK arithmetic on isolated simulation state; an actual maximum-balance override plus incoming value/SELFDESTRUCT had previously produced an HTTP panic. That red failure and repaired consumer are retained.

## Independent commitments and meaningful controls

Two actual HTTP blocks are independently reconstructed through unmodified SDK EVM/transition/system operations, state and receipt tries, BAL, withdrawals/requests, header hash and full RLP encoding. One allocates a new storage slot; the second seeds an override and exercises clear/refund/calldata-floor interaction. Both match complete state/transaction/receipt/withdrawal/request/BAL commitments, paid and peak gas, header hashes and exact RLP sizes. The SDK scaffold initially omitted inherited slot metadata; that fixture defect was corrected according to the selected notes, with its failed comparison retained. [Hashes and roots](glamsterdam-simulate-v1-results-20261119.json).

Additional actual HTTP controls cover full transaction sender/nonces, uncapped calldata floors, strict contract senders, exact nonce/fee/intrinsic/value/gas/initcode errors, override key rules, boundary call counts, precompile warming, gap blocks, simulated BLOCKHASH and two genuinely built competing branches. A hash-selected simulation reads its side-branch ancestor while the canonical head remains on the other branch. Synthetic/native logs, reverted value transfers and timeout cases preserve canonical head/state/nonces/balances.

Fifteen compiling mutations are detected: validation gas/nonce policy, uncapped default reservation, global gas budget, cross-block state, pre-block systems, withdrawals, BAL index, RLP size, precompile relocation, transfer rollback/deduplication, selected ancestry, uint256 balances and execution cancellation. Sources are restored before final checks. All 212 Go packages, 27 tagged Core/EIP packages and 48 affected race packages pass, with affected vet and local build. The subsequent PR 85 test-only composition receives its own affected repeat.
